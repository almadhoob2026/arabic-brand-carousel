محرر الكاروسيل العربي

حرّر هوية التصميم وبيانات الشرائح؛ المعاينة تعمل محليًا دون إرسال المحتوى لأي خادم.

الشرائح

المعاينة المباشرة
1080 × 1350 بكسل · اتجاه RTL

الملفات والتصدير

المحرر التجريبي مع محرك الذوق يعمل دون حساب أو اتصال إنترنت.

قبل النشر

افحص صحة المعلومات ومصادرها بنفسك. المعاينة النصية تقديرية وقد تختلف عن محرّك Chromium في المشروع. استخدم الأمر python scripts/render.py للإخراج الإنتاجي المتطابق مع ملفات المهارة.

اختصارات

زر السابق والتالي للتنقل بين الشرائح، الأسهم للأعلى والأسفل لإعادة ترتيبها، ويمكن تحميل JSON وتعديله وإعادة استيراده.

الخصوصية

يُقرأ ملف JSON والصور داخل المتصفح فقط (FileReader)، ولا تُستخدم روابط صور خارجية ولا يُرسل أي شيء لخادم. النصوص تُرسم باستخدام Canvas ولا يتم تنفيذ أي شفرة مستوردة، وتُرفض ملفات SVG التي تحتوي سكربتات أو روابط خارجية.
