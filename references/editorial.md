# Editorial playbook

## Start with audience value
Define reader, reading context, 1-sentence takeaway, desired behavior, objection and angle. Avoid generic listicles and filler. Favor concrete, actionable, accurately bounded content.

## Story structures
- Practical: Hook → problem → 3 steps → example → checklist → CTA.
- Comparison: Decision → criteria → side A → side B → tradeoff → takeaway.
- Myth/fact: Hook → claim → evidence → explanation → implication → CTA.
- Narrative: Event → tension → turning point → learning → next action.

Each slide communicates one independent, novel insight; each transition creates a reason to swipe. Do not force the default 7 if fewer slides serve better.

## Writing rules
- Prefer plain precise Arabic. Short subject-verb sentences. No unneeded jargon.
- One promise in cover; keep honest, not misleading clickbait.
- Headline is a message, not a topic label.
- Aim <35 words per slide; rewrite when visual fit fails.
- Keep at most one CTA and only when relevant.
- If user specifies Bahraini/Gulf dialect, use idiomatic natural wording without making formal institutions sound slangy.

## Evidence ledger
For each externally checkable claim, record: slide number, exact sentence, evidence URL, publisher, publication date, accessed date when needed, source status (verified/unverified/example), and note. Verify before writing numbers or causal assertions. Avoid source laundering: a cited page should actually support the claim. Examples and hypothetical values must be explicitly tagged.

## Editorial failure modes
Unsupported statistics; misleading before/after claims; split sentences that need another slide to make sense; identical slide structures; vague CTA; overly dense body; formal and dialect writing mixed without intent; arbitrary 'save and share' instructions.
